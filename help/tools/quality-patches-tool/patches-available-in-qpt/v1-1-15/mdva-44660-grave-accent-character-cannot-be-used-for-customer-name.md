# MDVA-44660: Für den Namen des Kunden kann kein Zeichen für einen Grabakzent (&grave;) verwendet werden.

Der Patch MDVA-44660 behebt das Problem, dass der Grave Accent Character (\`) nicht für den Namen eines Kunden verwendet werden kann. Dieser Patch ist verfügbar, wenn das [Quality Patches Tool (QPT)](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.15 installiert ist. Die Patch-ID lautet MDVA-44660. Beachten Sie, dass das Problem voraussichtlich in Adobe Commerce 2.4.5 behoben wird.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.2-p2

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.2-p1 - 2.4.4

>[!NOTE]
>
>Der Patch könnte mit neuen Versionen des Quality Patches Tool auf andere Versionen anwendbar werden. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Das Zeichen für einen schwerwiegenden Akzent (\`) kann nicht für den Vor- und Nachnamen eines Kunden verwendet werden.

<u>Schritte zur Reproduktion</u>:

Erstellen Sie einen neuen Kunden aus dem Admin-Konto oder registrieren Sie sich auf der Storefront mit dem Zeichen Grave Accent im Vor- oder Nachnamen, z. B. „L&#39;Epicerie“.

<u>Erwartete Ergebnisse</u>:

Es kann ein neuer Kunde mit dem Grabakzent im Namen erstellt werden.

<u>Tatsächliche Ergebnisse</u>:

*Vorname ist ungültig!* oder *Nachname ist ungültig* wird ein Fehler angezeigt.
