# ACP2E-4998: Fehlende SKU verhindert Massenstufen-Preisaktualisierungen für gültige Produkte

Mit dem Patch ACP2E-4998 wird das Problem behoben, dass die `POST /V1/products/tier-prices` REST-API-Anfrage vollständig fehlschlug, wenn keine SKU in der Payload vorhanden war, was verhinderte, dass gültige SKUs aktualisiert wurden. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 installiert ist. Die Patch-ID lautet ACP2E-4998. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.7 - p10

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Die `POST /V1/products/tier-prices` REST-API-Anfrage ist vollständig fehlgeschlagen, wenn keine SKU in der Payload vorhanden war, was verhindert hat, dass gültige SKUs aktualisiert wurden.

<u>Schritte zur Reproduktion</u>:

1. Identifizieren Sie eine vorhandene Produkt-SKU, z. B. `product_dynamic_1`, und eine SKU, die nicht im Katalog vorhanden ist, z. B. `product_dynamic_001`.
1. Senden Sie eine POST-Anfrage an `/rest/V1/products/tier-prices`, die beide SKUs in derselben Payload enthält:

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>Erwartete Ergebnisse</u>:

1. Der Stufenpreis wird für die vorhandene SKU gespeichert.
1. Die Antwort meldet die fehlende SKU als Fehler auf Elementebene.

<u>Tatsächliche Ergebnisse</u>:

1. Die Anfrage schlägt mit dem Fehler fehl *Das Produkt mit der SKU &quot;%1“ ist nicht vorhanden.* für `product_dynamic_001`.
1. Für die vorhandene SKU wird kein Stufenpreis gespeichert.
