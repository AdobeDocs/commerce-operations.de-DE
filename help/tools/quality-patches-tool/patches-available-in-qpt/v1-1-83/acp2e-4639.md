# ACP2E-4639: Anforderungslistenelementtyp im Adobe Commerce GraphQL-Schema falsch geschrieben

Der Patch ACP2E-4639 behebt das Problem, dass der Elementtyp der Anforderungsliste im GraphQL-Schema falsch geschrieben wurde. Das neue `requisition_list_items` gibt den korrekt geschriebenen `RequisitionListItems` zurück, während das ältere `items`-Feld und der `RequistionListItems`-Typ weiterhin verfügbar sind, aber veraltet sind. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 installiert ist. Die Patch-ID lautet ACP2E-4639. Dieses Problem wurde in Adobe Commerce B2B 1.5.3 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) B2B 1.5.2 - p1

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Der Elementtyp der Anforderungsliste ist im GraphQL-Schema falsch `RequistionListItems`. Das Feld „Ältere `items`&quot; und der `RequistionListItems` sind weiterhin verfügbar, werden aber nicht mehr unterstützt.

<u>Voraussetzungen</u>:

Adobe Commerce mit der B2B-Erweiterung.

<u>Schritte zur Reproduktion</u>:

1. Senden Sie die folgende GraphQL-Introspektionsabfrage:

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. Überprüfen Sie in der Antwort den Typ, den das `items` zurückgibt.

<u>Erwartete Ergebnisse</u>:

1. Das Feld `requisition_list_items` gibt den korrekt geschriebenen `RequisitionListItems` zurück.
1. Das `items` Feld und der `RequistionListItems` bleiben verfügbar und werden als veraltet markiert.

<u>Tatsächliche Ergebnisse</u>:

Das Feld `items` gibt den falsch geschriebenen `RequistionListItems` zurück, und kein Feld gibt den korrekt geschriebenen `RequisitionListItems` zurück.
