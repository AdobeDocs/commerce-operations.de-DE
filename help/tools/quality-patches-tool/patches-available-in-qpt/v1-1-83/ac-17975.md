# AC-17975: Kompatibilitätsprobleme mit PHP 8.5 betreffen CLI-Befehle, Kategoriebearbeitung, Designkonfiguration und Kundenanmeldung

Der AC-17975 Patch behebt das Problem, dass CLI-Befehle, Kategoriebearbeitung, Design-Konfiguration und AJAX-Kundenanmeldung in Adobe Commerce 2.4.9 fehlschlagen, wenn PHP 8.5 verwendet wird. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 installiert ist. Die Patch-ID ist AC-17975. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.9-p1 und 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

CLI-Befehle, Kategoriebearbeitung, Designkonfiguration und AJAX-Kundenanmeldung schlagen fehl, wenn Adobe Commerce 2.4.9 auf PHP 8.5 ausgeführt wird.

<u>Voraussetzungen</u>:

PHP 8.5 ist installiert.

<u>Schritte zur Reproduktion</u>:

1. Führen Sie den folgenden CLI-Befehl aus:

   ```
   bin/magento --version
   ```

1. Schließen Sie in der Storefront einen Checkout ab und melden Sie sich während des Checkouts an, während das Kunden-CAPTCHA für die Anmeldung und den Checkout aktiviert ist.
1. Öffnen Sie in Admin eine Kategorie, wenn für ein Kategorieattribut `null` festgelegt `frontend_input`.
1. Navigieren Sie in der Admin Console zu **[!UICONTROL Content]** > **[!UICONTROL Design]** > **[!UICONTROL Configuration]** und klicken Sie in der **[!UICONTROL Action]** Spalte auf **[!UICONTROL Edit]** für eine Shop-Ansicht.


<u>Erwartete Ergebnisse</u>:

Alle Vorgänge wurden erfolgreich abgeschlossen.


<u>Tatsächliche Ergebnisse</u>:

Die Vorgänge schlagen mit Fehlern fehl, z. B.:

```

/var/www/html/vendor/magento/framework/App/Config/ScopeCodeResolver.php on line 62
```

```

```

```

Undefined constant "Magento\Framework\Setup\Mvc\GLOB_BRACE"
```

```

```
