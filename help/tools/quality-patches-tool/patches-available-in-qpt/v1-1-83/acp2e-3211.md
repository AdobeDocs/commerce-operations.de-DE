# ACP2E-3211: Parallele Add-to-Cart-Anfragen erstellen separate Artikel für dieselbe SKU

Mit dem Patch ACP2E-3211 wird das Problem behoben, dass beim Hinzufügen desselben Produkts zum Warenkorb gleichzeitig in der Storefront separate Artikel im Warenkorb für dieselbe SKU erstellt werden, anstatt sie in einem einzigen Artikel zu kombinieren. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 installiert ist. Die Patch-ID lautet ACP2E-3211. Beachten Sie, dass dieses Problem in Adobe Commerce 2.4.8 behoben wurde.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5-p7

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Wenn Sie dasselbe Produkt gleichzeitig in der Storefront zum Warenkorb hinzufügen, werden separate Artikel im Warenkorb für dieselbe SKU erstellt, anstatt sie zu einem einzigen Artikel zu kombinieren.

<u>Schritte zur Reproduktion</u>:

1. Erstellen Sie ein neues Produkt.
2. Erstellen Sie ein neues Kundenkonto und melden Sie sich an.
3. Wechseln Sie zur Produktseite, öffnen Sie **Entwicklungs** > **Netzwerk** und fügen Sie das Produkt zum Warenkorb hinzu.
4. Kopieren Sie die cURL-Anfrage (bash), um das Produkt zum Warenkorb hinzuzufügen.
5. Verwenden Sie die kopierte cURL-Abfrage in zwei Konsoleninstanzen, um sie so schnell wie möglich zweimal Trigger.

<u>Erwartete Ergebnisse</u>:

- Das Produkt wird als einzelner Warenkorbartikel mit `qty=2` hinzugefügt.

<u>Tatsächliche Ergebnisse</u>:

- Das Produkt wird als zwei separate Artikel in den Warenkorb gelegt.
