# ACP2E-5205: Große Kataloge verursachen langsames Laden von Kategorien und Zeitüberschreitungen in Admin

Der Patch ACP2E-5205 behebt das Problem, dass das Laden von Kategorien lange dauert oder ein Zeitüberschreitungsproblem verursacht hat, wenn eine große Anzahl von Kategorien und Produkten betroffen ist. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 installiert ist. Die Patch-ID lautet ACP2E-5205. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.9 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p3

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) >= 2.4.8 &lt; 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Das Laden von Kategorien dauert lange oder hat ein Zeitüberschreitungsproblem verursacht, wenn eine große Anzahl von Kategorien und Produkten betroffen ist.

<u>Schritte zur Reproduktion</u>:

1. Erstellen Sie *2500* **[!UICONTROL Categories]** und mindestens *10000* **[!UICONTROL Products]**:
   1. Erstellen Sie eine Kopie von `setup/performance-toolkit` und legen Sie sie in `./var` ab, um Profile bearbeiten zu können.
   1. Bearbeiten Sie das `small.xml` und legen Sie **[!UICONTROL Categories]** = *2500* und **[!UICONTROL Products]** = *250000* fest.
   1. `bin/magento setup:performance:generate-fixtures var/setup/performance-toolkit/profiles/ce/small.xml` ausführen.
1. Nachdem Sie Produkte und Kategorien erstellt haben, stellen Sie sicher, dass sie alle Anker sind, und führen Sie die Abfrage aus:

   ```
   UPDATE catalog_category_entity_int set value = 1 where attribute_id = (select attribute_id from eav_attribute where attribute_code = 'is_anchor');
   ```

1. Rufen Sie das Menü Admin auf und stellen Sie sicher, dass Sie eine tiefere Kategoriestruktur haben, und verschieben Sie dann Kategorie 2 tiefer in die Kategoriestruktur 1.
1. Neuindizieren.

<u>Erwartete Ergebnisse</u>:

Jede Kategorie wird beim ersten nicht zwischengespeicherten Versuch geöffnet und dauert nur einige Sekunden.

<u>Tatsächliche Ergebnisse</u>:

Das Öffnen der Kategorie dauert mehr als eine Minute.
