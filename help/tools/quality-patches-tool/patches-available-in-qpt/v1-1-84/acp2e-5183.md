# ACP2E-5183: Statische Inhaltsbereitstellung schlägt auf PHP 8.5 mit `@magento_import` fehl

Der Patch ACP2E-5183 behebt das Problem, dass die Bereitstellung statischer Inhalte in PHP 8.5 mit dem Fehler *Verwenden von null als Array-Offset ist veraltet* wenn ein Modul `LESS` eine Datei die `@magento_import`-Direktive verwendet. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID lautet ACP2E-5183. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.4 - 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Die Bereitstellung statischer Inhalte schlägt in PHP 8.5 fehl mit dem Fehler *Verwenden von null als Array-Offset ist veraltet* wenn ein Modul `LESS` eine Datei die `@magento_import`-Direktive verwendet.

<u>Voraussetzungen</u>:

PHP 8.5 ist installiert.

<u>Schritte zur Reproduktion</u>:

1. Aktivieren Sie ein benutzerdefiniertes Modul, das eine `email-inline.less` bereitstellt, die einen benutzerdefinierten E-Mail-Textkörperstil und eine `@magento_import`-Anweisung enthält.
1. Entfernen Sie statische Inhalte und generierte Dateien:

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. Führen Sie die Bereitstellung statischer Inhalte mit der kompakten Strategie aus:

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>Erwartete Ergebnisse</u>:

Die Bereitstellung statischer Inhalte wird erfolgreich abgeschlossen und generiert das kompilierte CSS für die vom Modul bereitgestellte `LESS`.

<u>Tatsächliche Ergebnisse</u>:

Die Bereitstellung statischer Inhalte wird beim Kompilieren der vom Modul bereitgestellten `email-inline.less`-Datei und der Berichte abgebrochen:

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
