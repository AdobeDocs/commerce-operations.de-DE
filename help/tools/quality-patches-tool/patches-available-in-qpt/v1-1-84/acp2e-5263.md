# ACP2E-5263: CSV-Export von Produkten stoppt frühzeitig und lässt Produkte aus

Mit dem Patch ACP2E-5263 wird ein Problem behoben, bei dem ein CSV-Produktexport gestoppt werden kann, bevor alle Produkte einbezogen werden, wodurch eine unvollständige Datei erzeugt wird. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID lautet ACP2E-5263. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p5

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Produktexporte in CSV können gestoppt werden, bevor alle Produkte einbezogen werden. Dadurch wird eine unvollständige Datei erzeugt.

<u>Schritte zur Reproduktion</u>:

1. Stellen Sie sicher, dass der Katalog mehrere Produkte und eine sekundäre Store-Ansicht enthält.
2. Verwenden Sie Testprodukte, bei denen für die sekundäre Store-Ansicht eine Bildbeschriftung festgelegt ist, aber für die standardmäßige Store-Ansicht kein entsprechendes Produktbild verfügbar ist.
3. Gehen Sie im Admin zu **[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**.
4. Legen Sie **[!UICONTROL Entity Type]** auf **[!UICONTROL Products]** fest und lassen Sie **[!UICONTROL Export File Format]** auf **[!UICONTROL CSV]**.
5. Lassen Sie die Exportfilter leer und schließen Sie keine Attribute aus.
6. Scrollen Sie nach unten und klicken Sie auf **[!UICONTROL Continue]**.
7. Warten Sie, bis der asynchrone Export abgeschlossen ist, laden Sie dann die CSV-Datei herunter und öffnen Sie sie.

<u>Erwartete Ergebnisse</u>:

Der Export wird abgeschlossen und erzeugt eine CSV-Datei, die jedes Produkt enthält.

<u>Tatsächliche Ergebnisse</u>:

Der Export wird teilweise abgebrochen, aber der Administrator zeigt an, dass die Exportdatei bereit ist, und stellt eine CSV-Datei bereit, der einige Produkte fehlen.
