# ACP2E-5242: GraphQL verwendet die Store-ID als Website-ID bei Anfragen zum Hinzufügen zum Warenkorb

Mit dem Patch ACP2E-5242 wird das Problem behoben, dass beim Überprüfen der Produktverfügbarkeit beim Hinzufügen von Artikeln zum Warenkorb ein Fehler angezeigt wird, der angibt, dass die Website nicht gefunden werden kann. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID lautet ACP2E-5242. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Beim Überprüfen der Produktverfügbarkeit beim Hinzufügen von Artikeln zum Warenkorb wird ein Fehler angezeigt, der darauf hinweist, dass die Website nicht gefunden werden kann.

<u>Schritte zur Reproduktion</u>:

1. Melden Sie sich beim Admin Panel an.
1. Gehen Sie zu **Admin** > **[!UICONTROL Stores]** > **Einstellungen** > **[!UICONTROL All Stores]** und klicken Sie auf **[!UICONTROL Create Store View]**.
1. Erstellen Sie beispielsweise eine zweite Store-Ansicht mit dem Namen „store_2“.
1. Erstellen Sie einen leeren Gastkorb mit einer GraphQL-Anfrage unter Verwendung der HTTP-Kopfzeile „Store: store2“.
1. Zeichnen Sie die zurückgegebene Warenkorb-ID auf.
1. Fügen Sie mit einer GraphQL-Anfrage ein einfaches Produkt zum Warenkorb hinzu, indem Sie die HTTP-Kopfzeile „Store: store2“, die Produkt-SKU und die Warenkorb-ID verwenden.

<u>Erwartete Ergebnisse</u>:

Das Produkt wurde über die GraphQL-Anfrage erfolgreich zum Warenkorb hinzugefügt.

<u>Tatsächliche Ergebnisse</u>:

Die GraphQL-Anfrage schlägt fehl und schreibt die Meldung „Die angeforderte Website mit der ID … wurde nicht gefunden. Bitte die Website überprüfen und erneut versuchen.“ auf var/log/exception.log.
