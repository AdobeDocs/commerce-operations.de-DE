# AC-15494: Abfrage von GraphQL-Produkten gibt Produktnamen mit HTML-Escape-Zeichen zurück

Mit dem AC-15494-Patch wird das Problem behoben, bei dem die `products`-Abfrage Produktnamen mit HTML-Escape-Sonderzeichen anstelle der Originalzeichen zurückgibt. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID ist AC-15494. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.9 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p5

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Die `products` Abfrage gibt Produktnamen mit HTML-Escape-Sonderzeichen anstelle der Originalzeichen zurück.

<u>Schritte zur Reproduktion</u>:

1. Erstellen Sie ein neues Produkt mit dem Namen `55" 4K UHD Smart TV` mit SKU-`testsku`.
1. Senden Sie die folgende GraphQL-Abfrage:

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>Erwartete Ergebnisse</u>:

Die `products` Abfrage gibt den gespeicherten Produktnamen mit den ursprünglichen doppelten Anführungszeichen zurück.

<u>Tatsächliche Ergebnisse</u>:

Der zurückgegebene Produktname enthält doppelte Anführungszeichen mit HTML-Escape-Zeichen anstelle der Originalzeichen.
