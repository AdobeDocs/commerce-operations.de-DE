# ACP2E-5027: Indexer werden nicht beendet, wenn die Anwendungssperre den Dateisperranbieter verwendet

Mit dem Patch ACP2E-5027 wird das Problem behoben, dass Indexer nie beendet werden, da sie weiterhin versuchen, eine eigene Sperre zu erhalten, wenn `use_application_lock` aktiviert und der Dateisperrenanbieter konfiguriert ist. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID lautet ACP2E-5027. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.9

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.4 - 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Indexer werden nie beendet, da sie weiterhin versuchen, ihre eigene Sperre zu erhalten, wenn `use_application_lock` aktiviert und der Dateisperranbieter konfiguriert ist.

<u>Schritte zur Reproduktion</u>:

1. Aktivieren Sie `app/etc/env.php` die Anwendungssperre für Indexer und legen Sie den Sperranbieter auf Datei fest:

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. Ausführen des `catalog_product_category`:

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>Erwartete Ergebnisse</u>:

Die `catalog_product_category` Neuindizierung wurde erfolgreich abgeschlossen.

<u>Tatsächliche Ergebnisse</u>:

Die Neuindizierung wird nie abgeschlossen.
