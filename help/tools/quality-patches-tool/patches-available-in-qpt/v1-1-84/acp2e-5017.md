# ACP2E-5017: Abfrage der GraphQL-Kundenrolle schlägt für Kunden ohne Unternehmen fehl

Mit dem Patch ACP2E-5017 wird das Problem behoben, dass das Feld `role` der Abfrage &quot;GraphQL `customer`&quot; *Interner Server-Fehler* für einen Kunden zurückgibt, der keinem Unternehmen zugewiesen ist. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 installiert ist. Die Patch-ID lautet ACP2E-5017. Dieses Problem wird voraussichtlich in Adobe Commerce B2B 1.5.4 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) B2B 1.5.3

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Das `role` Feld der GraphQL-`customer`-Abfrage gibt *Interner Serverfehler)* einen Kunden zurück, der keinem Unternehmen zugewiesen ist.

<u>Voraussetzungen</u>:

B2B ist installiert.

<u>Schritte zur Reproduktion</u>:

1. Wechseln Sie in Admin zu **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**, legen Sie **[!UICONTROL Enable Company]** auf *[!UICONTROL Yes]* fest und klicken Sie auf **[!UICONTROL Save Config]**.
1. Erstellen Sie ein Kundenkonto, das keinem Unternehmen zugewiesen ist.
1. Senden Sie die folgende GraphQL-Abfrage mit einem gültigen Kunden-Token:

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>Erwartete Ergebnisse</u>:

Die Abfrage gibt die Kundendaten mit der `role` &quot;*&quot;* Fehler zurück.

<u>Tatsächliche Ergebnisse</u>:

Die Abfrage gibt *Interner Server-Fehler* zurück.
