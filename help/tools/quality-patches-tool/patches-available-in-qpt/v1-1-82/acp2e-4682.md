# ACP2E-4682: Storefront-Seiten, die Zitate überprüfen `isActive` leere Zitateinträge erstellen

Mit dem Patch ACP2E-4682 wird das Problem behoben, dass beim Besuch einer Storefront-Seite, die den `isActive` prüft, bei jedem Laden der Seite leere Anführungszeichen erstellt werden. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 installiert ist. Die Patch-ID lautet ACP2E-4682. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.7-p8

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5 - 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=de). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Beim Besuch einer Storefront-Seite, die den `isActive` prüft, wird jedes Mal, wenn die Seite geladen wird, ein leerer Anführungszeichen-Datensatz erstellt.

<u>Schritte zur Reproduktion:</u>

1. Passen Sie eine Storefront-Produktseite an und fügen Sie einen Block hinzu, der den `isActive` des Angebots überprüft.
1. Bei einem Kundenkonto anmelden.
1. Laden Sie die Produktseite in die Storefront neu.
1. Führen Sie die folgende Abfrage aus:

   ```
   SELECT COUNT(*) FROM quote;
   ```

1. Beachten Sie, dass die Anzahl der Angebote mit jedem Laden der Produktseite ansteigt.

<u>Erwartete Ergebnisse:</u>

1. Beim Laden der Seite wird kein leerer Anführungseintrag erstellt.

<u>Tatsächliche Ergebnisse:</u>

1. Jedes Mal, wenn eine Seite mit der `isActive` Angebotsprüfung besucht wird, wird ein leerer Angebotssatz erstellt.
