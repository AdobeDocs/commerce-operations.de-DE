# ACP2E-4797: Admin-WYSIWYG-Editor und Page Builder blockieren 4-Byte-Unicode-Zeichen, wenn utf8mb4 unterstützt wird

Der Patch ACP2E-4797 behebt das Problem, dass die Eingabe von 4-Byte-Unicode-Zeichen in den WYSIWYG-Editor oder Page Builder-Inhalt in der Admin fälschlicherweise blockiert wird, selbst wenn die Datenbank für die Unterstützung von utf8mb4 konfiguriert ist. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 installiert ist. Die Patch-ID lautet ACP2E-4797. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p4

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Sie können keine 4-Byte-Unicode-Zeichen im Admin WYSIWYG-Editor oder Page Builder speichern, selbst wenn die Datenbank für die Unterstützung von utf8mb4 konfiguriert ist.

<u>Voraussetzungen</u>:

* WYSIWYG ist aktiviert.
* Page Builder ist aktiviert.
* Die Datenbank ist für die Unterstützung von utf8mb4 konfiguriert.

<u>Schritte zur Reproduktion</u>:

1. Melden Sie sich beim Administrator an.
1. Navigieren Sie zu **[!UICONTROL Content]** > **[!UICONTROL Elements]** > **[!UICONTROL Blocks]**.
1. Klicken Sie auf **[!UICONTROL Add New Block]** oder öffnen Sie einen vorhandenen Block im Bearbeitungsmodus.
1. Geben Sie im Abschnitt **[!UICONTROL Content]** diese Emojis im Editor ein: 🔵⚪🔴.
1. Um das Problem in Page Builder zu reproduzieren, wählen Sie **[!UICONTROL Edit with Page Builder]** aus. Ziehen Sie bei Bedarf **[!UICONTROL Text]** aus der **[!UICONTROL Elements]** auf die Bühne, öffnen Sie die Einstellungen für den Inhaltstyp Text und geben Sie diese Emojis im Editor ein: 🔵⚪🔴.
1. Speichern Sie die Page Builder-Änderungen. Wenn Page Builder im Vollbildmodus geöffnet ist, schließen Sie den Vollbildmodus, um zum Blockformular zurückzukehren. Klicken Sie dann auf den **[!UICONTROL Save]** Pfeil und wählen Sie **[!UICONTROL Save & Close]** aus.

<u>Erwartete Ergebnisse</u>:

Der Block wird erfolgreich gespeichert und der Emoji-Inhalt bleibt im gespeicherten Inhalt.

<u>Tatsächliche Ergebnisse</u>:

Es wird die Fehlermeldung *Bitte entfernen Sie ungültige Zeichen* angezeigt.
