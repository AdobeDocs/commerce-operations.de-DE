# ACP2E-4840: Abfrage von GraphQL-Produkten gibt Null-Mengen für vorrätige Produkte in benutzerdefinierten Lagerbeständen zurück

Mit dem Patch ACP2E-4840 wird das Problem behoben, dass das Mengenfeld in der GraphQL-Abfrage für Produkte null für Produkte zurückgibt, die auf Lager sind und für benutzerdefinierte Lagerbestände zum Verkauf verfügbar sind. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 installiert ist. Die Patch-ID lautet ACP2E-4840. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p4

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Das Mengenfeld in der GraphQL-Abfrage „Produkte“ gibt null für Produkte zurück, die auf Lager sind und für benutzerdefinierte Lagerbestände zum Verkauf stehen.

<u>Voraussetzungen</u>:

MSI ist aktiviert.

<u>Schritte zur Reproduktion</u>:

1. Erstellen Sie eine neue Quelle.
1. Navigieren Sie in der Seitenleiste Admin zu **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Klicken Sie auf **[!UICONTROL Add New Stock]**.
1. Erweitern Sie **[!UICONTROL Sales Channels]** und wählen Sie die **[!UICONTROL Websites]** aus, in der das Lager verfügbar ist.
1. Erweitern Sie **[!UICONTROL Sources]**, klicken Sie auf **[!UICONTROL Assign Sources]**, wählen Sie die zuzuweisende Quelle aus und klicken Sie auf **[!UICONTROL Done]**.
1. Navigieren Sie in der Admin-Seitenleiste zu **[!UICONTROL Catalog]** > **[!UICONTROL Products]** und öffnen Sie ein vorhandenes Produkt im Bearbeitungsmodus.
1. Weisen Sie im Abschnitt **[!UICONTROL Sources]** die benutzerdefinierte Quelle zu, legen Sie **[!UICONTROL Source Item Status]** auf **[!UICONTROL In Stock]** fest, geben Sie einen Wert ungleich null für **[!UICONTROL Qty]** ein und speichern Sie das Produkt.
1. Bestätigen Sie in **[!UICONTROL Catalog]** > **[!UICONTROL Products]**, dass das Produkt einen **[!UICONTROL Salable Quantity]** ungleich null für die Website anzeigt, die dem benutzerdefinierten Lager zugewiesen ist.
1. Führen Sie die folgende `products`-[!DNL GraphQL]-Abfrage für diese SKU für die Store-Ansicht aus, die der Website zugewiesen ist, die den benutzerdefinierten Stock verwendet:

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Beobachten Sie die Antwort:

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Erwartete Ergebnisse</u>:

Die GraphQL-Antwort gibt einen Mengenwert ungleich null für Produkte zurück, die sich auf Lager befinden und auf der aktuellen Filiale/Website verkauft werden können.

<u>Tatsächliche Ergebnisse</u>:

Die GraphQL-Antwort gibt `quantity = null` zurück, während `stock_status` = `IN_STOCK` für Produkte ist, die vorrätig sind und im Admin verkauft werden können, wenn der Store ein benutzerdefiniertes MSI-Lager verwendet.
