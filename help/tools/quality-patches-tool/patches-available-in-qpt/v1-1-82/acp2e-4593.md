# ACP2E-4593: Falsche Website-Einschränkung CMS-Seite wird auf der sekundären Website in Storefronts mit mehreren Websites bereitgestellt

Mit dem Patch ACP2E-4593 wird das Problem behoben, dass in Setups mit mehreren Websites die falsche Seite Website-Einschränkung CMS auf der sekundären Website-Storefront bereitgestellt wird, da der Cache-Schlüssel der Landingpage nicht für jede Website gilt. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 installiert ist. Die Patch-ID lautet ACP2E-4593. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5-p15

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5 - 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Die falsche CMS-Seite für die Website-Einschränkung wird in Setups für mehrere Websites auf der sekundären Website-Storefront bereitgestellt, da der Cache-Schlüssel für die Landingpage nicht für jede Website gilt.

<u>Voraussetzungen</u>:

Inventar ist installiert.

<u>Schritte zur Reproduktion</u>:

1. Erstellen Sie zwei Websites.
1. Erstellen Sie zwei CMS-Seiten, fügen Sie jeder Seite im Inhaltsabschnitt unterschiedlichen Text hinzu und weisen Sie jede Seite einer anderen Website zu.
1. Aktivieren von Website-Einschränkungen und Konfigurieren einer Landingpage für die entsprechende Website.
1. Stellen Sie sicher, dass die Zwischenspeicherung aktiviert ist.
1. Öffnen Sie die Storefront für die erste Website und überprüfen Sie den angezeigten Landingpage-Inhalt.
1. Öffnen Sie die Storefront für die zweite Website und achten Sie darauf, dass dort weiterhin der Landingpage-Inhalt von der ersten Website angezeigt wird.

<u>Erwartete Ergebnisse</u>:

Jede Website zeigt ihre jeweilige CMS-Seite korrekt in der Storefront an.

<u>Tatsächliche Ergebnisse</u>:

Auf beiden Websites wird dieselbe CMS-Seite angezeigt. Dies ist die Seite, auf die zuerst zugegriffen wurde.
