# ACP2E-5046: Durch Aktualisieren der Seite beim Erstellen einer Bestellung in Admin wird dieselbe SKU mehrmals hinzugefügt

Mit dem Patch ACP2E-5046 wird das Problem behoben, dass beim Aktualisieren der Seite beim Erstellen einer Bestellung in Admin dieselbe SKU mehrmals hinzugefügt wird. Dieser Patch ist verfügbar, wenn [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 installiert ist. Die Patch-ID lautet ACP2E-5046. Dieses Problem wird voraussichtlich in Adobe Commerce 2.4.10 behoben.

## Betroffene Produkte und Versionen

**Der Patch wird für die Adobe Commerce-Version erstellt:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.8-p4

**Kompatibel mit Adobe Commerce-Versionen:**

* Adobe Commerce (alle Bereitstellungsmethoden) 2.4.5 - 2.4.9

>[!NOTE]
>
>Der Patch könnte mit neuen [!DNL Quality Patches Tool]-Versionen auch für andere Versionen gelten. Um zu überprüfen, ob der Patch mit Ihrer Adobe Commerce-Version kompatibel ist, aktualisieren Sie das `magento/quality-patches` auf die neueste Version und überprüfen Sie die Kompatibilität auf der Seite [[!DNL Quality Patches Tool]: Nach Patches suchen](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Verwenden Sie die Patch-ID als Suchbegriff, um den Patch zu finden.

## Problem

Wenn Sie die Seite beim Erstellen einer Bestellung in Admin aktualisieren, wird dieselbe SKU mehrmals hinzugefügt.

<u>Schritte zur Reproduktion</u>:

1. Navigieren Sie im Admin-Bedienfeld zu **[!UICONTROL Sales]** > **[!UICONTROL Orders]**.
1. Klicken Sie auf **[!UICONTROL Create New Order]** und wählen Sie einen Kunden aus.
1. Klicken Sie auf **[!UICONTROL Add Products By SKU]**.
1. Geben Sie die SKU eines vorhandenen Produkts und eine Menge ein und klicken Sie dann auf **[!UICONTROL Add to Order]**.
1. Aktualisieren Sie die Seite, bestätigen Sie die erneute Übermittlung des Formulars, wenn der Browser Sie dazu auffordert, und überprüfen Sie die Anzahl der hinzugefügten SKU.

<u>Erwartete Ergebnisse</u>:

Die SKU bleibt nach dem Aktualisieren der Seite auf der eingegebenen Menge.

<u>Tatsächliche Ergebnisse</u>:

Bei jeder Seitenaktualisierung wird dieselbe SKU erneut hinzugefügt, wodurch die Anzahl der Seiten steigt.
